# Backlog

가칭 `img_reader`의 성능 개선과 제품 방향을 위한 우선순위 메모다.

## 제품 방향

- 포지션은 `mac용 이미지 뷰어`로 잡는다.
- 구현 방향은 `Rust core + Swift shell`이다.
- 핵심 읽기 경험은 `스크롤 뷰어`를 유지한다.
- 단축키는 지금 앱 수준의 조작감을 목표로 유지한다.
- 이어읽기는 복잡하게 두지 않고 `최근 파일 목록 + 마지막 위치` 정도만 남긴다.
- EPUB, 북마크, 노트, 라이브러리 DB는 범위 밖으로 본다.
- 최근 파일 캐시는 JSON으로 둔다.
- cache 파일에는 파일 위치, 파일명, 페이지 번호 또는 압축파일 내부 파일명을 남긴다.
- 파일에 남는 기준은 `파일 위치 + 파일명` 조합을 unique 키로 쓴다.
- 이어읽기 옵션은 선택된 파일을 열 때 처음부터 읽을지 최근 위치부터 읽을지 묻는 팝업 유무를 토글한다.
- 옵션을 끄면 팝업 없이 무조건 첫 이미지부터 연다.

## UI 방향

- 기본 화면은 최대한 심플하게 유지한다.
- 아무 파일도 열지 않았을 때는 file explorer가 보이는 상태로 둔다.
- 기본 진입 화면은 이미지 뷰어 중심으로 가져간다.
- `file explorer`는 왼쪽 사이드 패널로 둔다.
- `file explorer`는 이미지 뷰어를 가리지 않는다.
- `file explorer`는 단축키나 아이콘으로 열고 닫을 수 있다.
- `file explorer`는 폭 조절이 가능하게 둔다.
- 최근 읽은 파일은 `file explorer` 하단에 배치한다.
- 최근 파일을 선택하면 최근 위치부터 읽을지 묻는 팝업을 띄운다.
- `file explorer`에서 선택한 파일이 최근 읽은 파일이면 같은 이어읽기 팝업을 띄운다.
- 홈 화면처럼 보이는 복잡한 대시보드는 두지 않는다.
- `file explorer`는 디렉토리와 지원 파일을 같이 보여준다.
- 디렉토리를 선택하면 내부 파일 목록이 보인다.
- 지원하는 파일을 선택하면 바로 이미지 뷰어로 연다.
- 마지막으로 열었던 파일 자동 오픈은 옵션으로 둔다.
- 이어읽기 팝업은 상태 내용이 있는 cache 파일이 있을 때만 띄운다.
- `file explorer`에서 선택한 파일도 같은 cache 파일 규칙을 따른다.
- 이어읽기 기능은 옵션에서 토글할 수 있다.
- 토글 상태와 관계없이 cache 파일에는 위치 정보가 저장된다.

### 배포 목표

- 기본 배포는 `arm64 전용`을 우선 고려한다.
- 패키징 크기는 `10~25MB` 정도를 1차 목표로 본다.
- 유니버설 빌드는 추후 필요할 때만 고려한다.
- 이미지 리소스와 불필요한 런타임 의존성은 최대한 줄인다.

## 구현 방향

- 앱 구조는 mac 전용으로 단순하게 가져간다.
- UI는 Swift shell, core는 Rust로 나눠서 먼저 단순한 구조를 만든다.
- 스크롤 모드는 기존처럼 읽기 모드 전환으로 유지한다.
- 현재 위치는 복잡한 오프셋보다 현재 페이지 번호 중심으로 저장한다.
- 최근 파일 목록과 마지막 위치만 남기고, 무거운 DB는 두지 않는다.
- 전체 압축 해제 대신 필요할 때만 읽는 부분 추출과 캐시를 검토한다.
- 스크롤 뷰어는 기본 읽기 모드로 유지한다.
- 단축키는 현재 앱의 조작감을 기준으로 맞춘다.
- 저장 구조는 무거운 DB보다 최근 파일 히스토리 중심으로 단순화한다.
- Rust core와 Swift shell 사이의 전달 데이터는 경로/핸들/메타데이터 중심으로 가볍게 유지한다.
- 작은 압축파일은 열자마자 통째로 캐시하고, 큰 압축파일은 부분 캐시 + 프리페치로 간다.
- 캐시 용량 한도는 설정에서 조절할 수 있게 둔다.
- 캐시 한도는 메모리/디스크 각각 따로 다룰지 검토한다.
- 캐시는 흔한 이미지 뷰어 방식으로 시작하고, 성능을 보면서 프리페치 범위와 캐시 크기를 고도화한다.

## UI / UX 메모

- 기본 화면은 빈 화면에 가깝게 유지한다.
- 아무 파일도 없을 때는 file explorer를 기본 노출한다.
- 왼쪽 file explorer는 필요할 때만 드로어처럼 나온다.
- 최근 파일은 탐색 목록과 시각적으로 분리한다.
- 이어읽기 팝업은 `처음부터 / 최근 위치부터` 정도로 단순하게 유지한다.
- 이어읽기 팝업은 cache 파일이 있을 때만 표시한다.
- `file explorer`와 최근 파일 모두 동일한 팝업을 사용한다.
- 이어읽기 기능은 옵션 토글로 on/off 한다.
- 토글 상태와 무관하게 cache 파일에는 위치 정보를 남긴다.
- 페이지 이동 시 현재 위치는 짧은 오버레이나 토스트로만 알려준다.
- 단축키 힌트는 첫 실행이나 첫 오픈 때만 가볍게 보여준다.
- 드래그 앤 드롭 안내와 에러는 화면을 과하게 가리지 않게 둔다.
- 드래그 앤 드롭 안내는 적절한 수준으로만 넣는다.
- 드래그 앤 드롭은 Finder에서 앱으로 끌어오는 흐름을 기본으로 둔다.
- file explorer 폭과 같은 자주 쓰는 UI 상태는 기억한다.
- 이미지가 열려 있지 않은 상태에서는 사이드바가 열린 상태로 시작한다.
- file explorer가 활성일 때는 방향키, Enter, Backspace 중심으로 먼저 탐색한다.
- 위/아래 방향키는 항목 이동, Enter는 열기, Backspace는 상위 폴더로 간다.
- file explorer가 열려 있을 때는 reader용 단축키보다 탐색 입력을 우선한다.
- 캐시 한도 조절 UI는 설정 화면에 넣는다.

## 단축키 설계

### file explorer

- 자연스러운 탐색기 사용 경험을 우선한다.
- 방향키로 항목 이동, `Enter`로 열기, `Backspace`로 상위 폴더 이동을 기본으로 둔다.
- `file explorer`가 focus되면 탐색기 관련 단축키가 reader 단축키보다 우선한다.

### reader

- 이전 페이지
- 다음 페이지
- 10장 전
- 10장 후
- 이전 파일
- 다음 파일
- view 모드 전환: 스크롤 / 페이지
- 1장 보기
- 2장 보기
- fit 모드 전환: 폭 / 높이 / 균형

### 공용

- 설정창 열기
- file explorer 호출
- 새 창 띄우기
- 새 창은 별도 프로세스로 띄우는 방식을 우선 검토한다.

### 우선순위

- 공용 단축키를 제외한 나머지는 focus된 기능 기준으로만 동작한다.
- reader와 file explorer가 동시에 관련될 수 있는 입력은 현재 focus가 잡힌 쪽을 우선한다.
